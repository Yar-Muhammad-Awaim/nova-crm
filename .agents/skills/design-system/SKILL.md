# NovaWorks Venture Design System

Use this skill when designing or refactoring UI components to ensure an institutional, top-tier aesthetic worthy of high-valuation funding rounds ($50k+).

## Visual Identity Principles
1. **Precision & Density**: Clean information density inspired by Linear, Stripe, and Vercel. Avoid bloated empty white space or generic cartoonish AI illustration styles.
2. **Typography Hierarchy**:
   - Display: Instrument Serif for punchy, editorial headlines and key milestones.
   - Sans: Inter Tight for legible, crisp UI labels and tabular text.
   - Mono: Geist Mono for data points, timestamps, metrics, badges, and technical tags.
3. **Interactive Proof over Empty Claims**:
   - Provide interactive playgrounds, live simulators, and data-driven proof instead of static placeholder graphics.
4. **Color Tokens**:
   - Respect theme tokens (`nova`, `slate`, `white`, `sand`).
   - Use subtle borders (`hairline`, `border-border/60`), subtle radial glow effects, and muted dark backdrop blurs.
